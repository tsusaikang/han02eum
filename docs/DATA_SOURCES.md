# 데이터 출처와 제공 방식

현재 제품 구조의 출처·이용 조건·집계 해석을 설명하는 정본이다. 안내 갱신: 2026-10-29 (KST). 원천과 집계의 기준일은 아래에서 별도로 구분한다. 운영 상태는 [PROJECT_STATE.md](PROJECT_STATE.md), 추출·검색 구조는 [NATIVE_DICTIONARY_20260907_212917.md](NATIVE_DICTIONARY_20260907_212917.md)를 따른다.

## 현재 기본 검색

| 출처 | 가져오는 내용 | 화면에서 사용하는 방식 |
|---|---|---|
| [한국어판 위키낱말사전](https://ko.wiktionary.org/)의 영어 항목 | 영어 표제어, 한국어 풀이, 제공된 품사·발음·예문·용법 | 영어 검색어에 해당하는 원문 뜻을 표시한다. 공식 XML에서 추출한 제품 자료를 사용한다. |
| [국립국어원 한국어기초사전](https://krdict.korean.go.kr/) | 한국어 표제어, 한국어 정의, 영어 대응 표현·정의, 예문·발음·관련 정보 | 한국어 표제어로 찾거나, 원문 영어 대응 표현으로 한국어 항목을 역검색한다. |

영어 입력 시 두 자료를 함께 조회하고 출처별 결과를 같은 수준으로 표시한다. 같은 검색어로 결과가 나왔다는 이유로 서로의 뜻을 일치시키거나 새로운 번역으로 합치지 않는다. 한국어기초사전 대응 표현에는 한국어 문법 항목의 로마자 표기도 있어, 검색키 전체를 영어 단어 수로 부르지 않는다.

기본 검색의 뜻·표현은 원문 자료에서 제공한다. 과거 AI 의미 연결 실험을 기본 검색의 선행조건으로 삼거나 자동 재개하지 않는다. 추출 충실성 확인과 원문의 의미 정확성 평가는 구분한다.

## 외부 참고와 과거 자료

[영어판 Wiktionary](https://en.wiktionary.org/)는 결과 화면의 외부 영영 사전 참고 링크로만 안내한다. 기본 검색의 수록 원천에는 합산하지 않는다. 이전 검색은 지원이 종료됐으며, 공개 확인 기록은 [프로젝트 상태](PROJECT_STATE.md)를 따른다.

이전 검색의 별도 검토 연결208건과 원천·차단 기록은 보존한다. 저장공간 정리 여부는 자료의 현재 사용 여부만으로 결정하지 않는다. 2026-09-10 승인된 중복 자료 정리의 범위·남긴 대체본은 정리 결과 (로컬 보관 경로: `docs/STORAGE_CLEANUP_REVIEW_20260910_102848.md`), 당시 용량·Git 상태는 완료 이력 (로컬 보관 경로: `docs/PROJECT_HISTORY_20260909_234322.md #completed-20260910`)을 확인한다. 이 기록은 추가 삭제 지시가 아니다.

## 수록량 집계와 갱신

이용자용 [출처와 수록 범위](https://han02eum.com/dictionary-sources_20260909_235001.html)는 현재 기본 검색의 두 출처에 대해 표제어·검색 표현·뜻의 단위를 함께 표시한다. 현재 공개 상태는 PROJECT_STATE에서 확인한다.

집계 결과 정본은 [통계 JSON](../public/source-metadata_20260909_235001.json)이며 계산 방법은 [집계 프로그램](../scripts/build-source-metadata_20260909_235001.mjs)에 있다. 현재 기본 제품 검색 자료192개·상세256개를 읽어 다시 계산하며 과거 미사용 자산이나 비공개 입력은 집계하지 않는다. 원천/검색 자료를 교체하는 릴리스에서는 다음 명령으로 JSON을 갱신한 뒤 페이지와 함께 반영한다.

```sh
node scripts/build-source-metadata_20260909_235001.mjs
node --test test/source-metadata_20260909_235001.test.mjs test/dictionary-sources_20260909_235001.test.mjs
```

집계 결과 JSON의 생성 시각은 2026-09-10 08:28 KST다. 한국어판 원천은 2026-09-01 공식 XML 덤프이며, KRDict의 원천 전체 갱신일은 공개 제품 메타정보에 없어 추정하지 않는다. 이 문서를 2026-10-29에 정리한 것은 새 수집이나 재집계를 뜻하지 않는다.

표제어·뜻·저장된 검색키를 구분한다. 영어용 검색키에는 공백이 있는 표현과 로마자 표기도 포함되며, 두 출처의 같은 키는 같은 의미의 번역쌍을 뜻하지 않는다. 입력80자 제한과 한글 포함 시 한국어 검색으로 분기하는 규칙 때문에 저장된 키 수가 실제 입력 가능한 검색어 수와도 같지 않다. 예를 들어 위키의 `무명질`과 KRDict의 81자 영어 표현은 기본 영어 직접 조회 범위와 다르다. 이전 검색 자산·실시간 영어판 API·음원은 기본 두 출처의 수록량에 합산하지 않는다.

## 이용 조건과 원문 추적

- 현재 한국어판 제품 자료에는 원문 링크와 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)을 표시한다. 출처와 표시는 [제품 manifest](../public/native-english-ko_20260908_012503/manifest.json)에서 확인한다. 보존된 영어판 자료를 다시 다룰 때는 [Wiktionary 저작권 안내](https://en.wiktionary.org/wiki/Wiktionary:Copyrights)와 각 원문 조건을 함께 확인한다.
- 한국어기초사전 텍스트는 [국립국어원 저작권 정책](https://krdict.korean.go.kr/kor/kboardPolicy/copyRightTermsInfo)에 따른 출처·CC BY-SA 2.0 KR 표시를 유지한다. [공식 전체 내려받기](https://krdict.korean.go.kr/download/downloadPopup).
- 음원은 사전 텍스트와 구분하고 파일별 출처·이용 조건을 따른다. 현재 기본 화면의 발음 표기 제공과 음원 재생 기능은 같은 의미가 아니다.
- 보존된 영어판 API의 Wikimedia 연락처 설정과 기본 정적 검색의 차이는 [배포 안내의 설정 근거](CLOUDFLARE_DEPLOYMENT.md#설정-근거와-보존된-api)에서 확인한다.
