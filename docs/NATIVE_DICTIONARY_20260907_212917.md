# 원천 기반 영한·한영 사전

현재 검색 구조와 구현 경로를 설명하는 정본이다. 최초 작성: 2026-09-07, 안내 갱신: 2026-10-29 (KST). 원천 데이터의 기준일·수록량은 [데이터 출처 안내](DATA_SOURCES.md#수록량-집계와-갱신), 공개 반영 상태는 [프로젝트 상태](PROJECT_STATE.md)를 따른다.

영어판 Wiktionary의 뜻에 한국어 뜻을 매칭하는 작업을 검색의 선행조건으로 삼지 않는다.

## 제품 구조

- 기본 `/`: 한국어판 Wiktionary 영어 항목의 한국어 뜻을 보여 주는 영한 검색, 한국어기초사전 원문을 보여 주는 한영 검색.
- 영어 검색은 한국어판 Wiktionary와 한국어기초사전의 영어 대응표현을 함께 조회한다. 출처별 결과는 같은 수준으로 바로 펼쳐 보여 주며 기본/보조로 차등 표시하지 않는다. 전체 조회가 빈 결과일 때만 미수록 안내를 표시하고, 일부 조회 실패는 확인된 다른 결과를 유지하며 안내한다.
- 각 원문의 표제어·뜻·출처 경계는 유지한다. 한국어기초사전의 대응표현 관계를 Wiktionary 뜻의 exact 번역으로 만들지 않는다.
- 영어판 Wiktionary는 별도의 영영 원문 링크로 제공한다.
- `/legacy_20260907_205800.html`: 지원 종료된 주소에서 `?q=`를 유지해 기본 검색으로 이동한다. 이전 구현·자료 보존과 서비스 지원 여부는 구분한다.
- 기존 공유 주소 `?q=`를 유지하고 입력 언어로 검색 방향을 자동 판별한다. 방향 선택 버튼은 없으며 이전 `direction` 파라미터는 검색 방향을 강제하지 않는다. 검색 성공 알림은 화면 공간을 차지하지 않고 접근성 알림으로 제공한다.

## 입력과 공통 교정

2026-09-08 교정에서는 Kaikki 추출본과 별도로 공식 한국어판 20260901 XML을 확보하고, 원문 본문·품사 제목·언어 구역과 구형 틀을 처리하는 추출기를 수정했다. `tree`와 같은 본문 기본 뜻이 뒤의 품사 항목 때문에 빠지던 공통 조건을 고친 전체 추출본을 사용한다. 기존 raw·샤드·tree 보완 파일은 보존하되 개별 tree 보완 import는 새 전체 자료에서 제거한다. 최종 수량·실행·전수 차이는 [공통 교정 보고서](DATA_SOURCE_CORRECTION_20260908_014922.md)를 따른다.

원표제어와 뜻 경계를 유지한다. 공백·Unicode를 정규화하고 검색키는 소문자로 찾되, `US`와 `us`처럼 대소문자가 의미를 구별하면 정확 표제어 일치를 우선한다. 정확한 대소문자 표제어가 없으면 동일 검색키의 원표제어 후보를 각각 표시한다. 품사를 추정하지 않고 예문만의 한국어를 정의로 승격하지 않는다. 추출 오류와 한국어 풀이 없는 항목은 원시 자료에 보존하면서 제품 표시 여부를 별도로 기록한다.

2026-09-08 교정에서는 한국어기초사전 공식 전체 ZIP을 확보해 한국어/영어 원문 전용 자료를 재생성했다. 한국어/영어 뜻의 핵심 정보와 예문·주석·발음·관계를 보존한다. core와 역검색은 각각64샤드, 상세는256샤드이며 상세는 사용자가 펼칠 때만 가져온다. 기존 compact 자료는 지원이 종료된 구현의 보존 자료다.

영어 역검색은 원문 영어 대응표현으로 한국어 뜻을 찾는 기능이다. entity를 복원한 뒤 세미콜론 대안을 나누며 쉼표/슬래시 혼합구의 모호한 부분을 임의로 별도 단어로 만들지 않는다. 따라서 일부 이전 조각 키는 원문 전체 표현으로만 조회할 수 있다. 영어 대응표현 검색은 한국어 원문의 연결을 보여 주며 영어판 뜻에 대한 exact 번역으로 해석하지 않는다.

한영 결과는 용법과 발음을 표시하고 예문·관련 표현은 접힌 상세로 제공한다. 예문은 원문 그룹8개씩 더 볼 수 있다. 원천 공통 필드와 한국어/영어 상세를 보존하며 다른 언어의 대응표현은 원본 ZIP에 남긴다.

## 지원 종료된 구현과의 경계

기본 검색은 정적 자료를 읽으며 이전 `/api/lookup`을 호출하지 않는다. API·파서·검토 연결208건과 원천·차단 기록은 보존한다. 이전 화면의 뜻 계층·음원 처리와 당시 검사 방식은 지난 구조 기록 (로컬 보관 경로: `docs/PROJECT_HISTORY_20260909_234322.md #native-notes-before-20261029`)에 있다. 보존 파일이 있다는 이유로 이전 검색을 지원 중이라고 해석하지 않는다.

## 출처와 이용 조건

뜻별 원문 링크와 사전 데이터 라이선스 표시를 유지한다. 한국어판 자료는 공식 XML을 교정한 추출기로 가공한 제품이며, 추출 프로그램의 MIT 라이선스와 사전 원문의 이용 조건은 별개다. 출처·라이선스·발음 표기와 음원 구분은 [이용 조건과 원문 추적](DATA_SOURCES.md#이용-조건과-원문-추적)을 따른다. 원문 재추출은 [한국어판 재현 문서](KOWIKTIONARY_EXTRACTION_REPRODUCE_20260908_015950.md)를 확인한다.
