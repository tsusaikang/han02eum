## 한계

이번 완료 조건은 확인된 추출·변환·표시 오류를 공통 규칙으로 교정하고 원천의 해당 전체 자료에 적용하는 것이다. 원천 사전 자체의 오류·미수록·다의어 설명의 충분성까지 모두 해결했다는 뜻이 아니다. 구조 보존 비교와 개별 의미 정확성 심사는 구분한다. 신규 자료 갱신 때에는 같은 재현 가능한 추출·빌드와 전체 차이 비교를 적용한다.

원문 내용 자체의 후속 편집 검토 후보도 분리한다. 이번 형식 교정 후보에서 `tardiness`의 ‘품질이 늦어지는 사실’, `systematically`의 ‘체계적인’처럼 의미나 품사에 의문이 드는 원문 문구를 확인했다. 이번 변환에서는 임의 번역을 만들지 않고 원문대로 보존하며, 이 항목들을 정확한 뜻으로 승인했다는 의미가 아니다. 이 문제는 추출 누락 수복과 별개의 원문 편집 품질 문제다.
