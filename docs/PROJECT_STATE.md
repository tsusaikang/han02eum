# 말결 사전 — 공식 프로젝트 상태

마지막 갱신: 2026-08-20

## 현재 목표와 완료 조건

영어 또는 한국어 단어를 입력하면 발음, 뜻, 예문을 보여주는 영한·영영·한영 웹 사전 MVP를 만든다.

완료 조건:

- 영어/한국어 입력 자동 판별
- 영어 검색에서 발음, 한국어 번역, 영영 뜻, 예문 표시
- 한국어 검색에서 발음 표기, 영어 뜻, 가능한 예문 표시
- 데이터 출처·리비전·라이선스 확인 가능
- 데스크톱/모바일 반응형 UI와 기본 접근성
- 정상 검색, 한국어 검색, 결과 없음, 네트워크 오류 검증

## 확정된 결정과 이유

1. MVP 데이터는 영문 Wiktionary 공식 API를 사용한다. API 키 없이 양방향 의미·발음·용례를 한 출처에서 제공할 수 있고 원문 리비전까지 추적할 수 있기 때문이다.
2. 외부 API는 브라우저가 아니라 로컬 서버가 호출한다. User-Agent 정책 준수, 캐시, 오류 처리, 향후 속도 제한을 한곳에서 관리하기 위해서다.
3. 원문 HTML을 화면에 삽입하지 않고 필요한 텍스트만 구조화한다. 원치 않는 마크업 실행과 스타일 오염을 막기 위해서다.
4. 공개 데이터에 없는 뜻이나 예문을 AI로 생성해 채우지 않는다. 사전 정보의 출처와 불확실성을 보존하기 위해서다.
5. 대규모 덤프 수집·자체 DB·배포는 이번 단계에 포함하지 않는다. 각각 데이터 검수·운영비·라이선스 검토가 필요한 별도 출시 단계다.

## 완료한 작업

- Node.js 무의존 정적 서버와 `/api/lookup` 중계 API
- Unicode 정규화, 입력 길이·문자 검증, 10분/500항목 메모리 캐시
- Wikimedia 지연·호출 제한·누락·네트워크 오류 처리
- Wiktionary HTML에서 언어 구간, 품사, 정의, 예문, IPA, 음원, 한국어 번역 추출
- 반응형 검색/결과/오류 화면과 키보드 `/` 단축키
- 공개 음원 실패 시 브라우저 기기 음성 대체
- 원문 링크, 리비전 번호, CC BY-SA 4.0 표시
- 데이터 출처·운영 제약 문서화

## 산출물과 관련 파일

- 실행 서버: `server.mjs`
- 사용자 화면: `public/index.html`, `public/styles.css`, `public/app.js`
- 사전 파서: `public/dictionary-parser.js`
- 자동 테스트: `test/server.test.mjs`, `test/parser-helpers.test.mjs`
- 데이터 결정: `docs/DATA_SOURCES.md`
- 실행 안내: `README.md`

## 검증 결과

- `npm test`: 7/7 통과
- `npm run check`: 통과
- 실제 `hello`: IPA 3개, 한국어 번역 5개, 영영 뜻 7개와 예문 표시 확인
- 실제 `안녕`: 발음/로마자 표기 3개, 영어 뜻 4개와 예문 표시 확인
- 존재하지 않는 단어: 404 안내 확인
- 데스크톱 1440px과 기본 모바일 폭에서 레이아웃 확인
- 브라우저 경고/오류 로그: 없음

## 미해결 문제

- Wiktionary 문서 구조가 바뀌면 클라이언트 파서 보정이 필요하다.
- 단어별 한국어 번역과 예문의 완성도 편차가 크다.
- 전체 HTML 파서의 자동 회귀 테스트는 아직 브라우저 수동 검증에 의존한다.
- 서비스 명칭 ‘말결’, 코드 공개 라이선스, 상업 이용 여부는 사용자 확정이 필요하다.
- 운영 배포 위치와 공개 연락처 URL이 정해지지 않았다.

## 다음 단계

1. 사용자에게 브랜드·화면·데이터 품질을 검토받는다.
2. 운영 목적(개인/공개/상업)과 배포 환경을 확정한다.
3. 승인 시 브라우저 기반 파서 회귀 테스트와 인기 단어 품질 표본 검사를 추가한다.
4. 사용량이 확인된 뒤 Kaikki 덤프 기반 자체 색인을 별도 설계한다.

## 중요한 제약과 주의사항

- 운영 환경은 연락처가 포함된 `WIKIMEDIA_USER_AGENT`를 반드시 설정한다.
- Wiktionary 파생 내용의 출처 링크와 CC BY-SA 표시를 제거하지 않는다.
- 상용 사전 사이트를 스크래핑하거나, 출처가 다른 의미를 자동 병합하지 않는다.
- 덤프 다운로드·DB 구축·외부 배포는 별도 승인 없이는 진행하지 않는다.

## Git 체크포인트

- 로컬 Git 저장소를 `main` 브랜치로 초기화했다.
- 현재 MVP 전체를 첫 로컬 커밋으로 보존했다.
- 원격 저장소는 아직 연결하지 않았으며 외부 전송도 하지 않았다.

## 인수인계 체크포인트

MVP 구현과 로컬 실데이터 검증 단계까지 완료했다. 다음 작업은 사용자 검토 후 운영 목적과 배포 환경을 정하는 단계다. 현재 컨텍스트만으로 계속해도 충분하며 새 작업은 아직 필요하지 않다.
